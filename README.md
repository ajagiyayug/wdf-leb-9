================================================================================
PRACTICAL 09: Secure User Registration
================================================================================

OVERVIEW:
This practical focuses on building a secure user registration system for the
StudentHub portal using PHP and MySQL. It ensures that user credentials and
personal details are validated and safely stored in the database.

KEY FEATURES & OBJECTIVES:
1. Client-side and server-side validation for all input fields.
2. Checking for duplicate email addresses or usernames before inserting data.
3. Hashing user passwords securely using PHP's password_hash() before database storage.
4. Returning user-friendly success and error messages upon submission.

TECHNOLOGIES USED:
- PHP (MySQLi / PDO)
- MySQL Database
- HTML5 / CSS3 / JavaScript
- XAMPP / Web Server
